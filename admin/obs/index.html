채팅 추첨

OBS ‘채팅 추첨’ 화면에 표시

유튜브 채팅을 읽으려면 아래 ‘유튜브 채팅’에 API 키와 라이브 주소가 필요합니다. 키 없이도 ‘테스트 참여 10명’으로 화면을 확인할 수 있습니다.

오버레이 주소

주소에 비밀 키가 들어 있어 외부에 공유하지 마세요
방송 보드 (공지 · 메모 · 현재 순서 · 대기 목록)1920 × 1080 (가로)
미리보기

가로 방송용 한 화면입니다. 위에 공지 두 줄과 연결 상태, 왼쪽에 메모와 힛카드, 오른쪽 위에 지금 개봉 중인 사람, 오른쪽 아래에 대기 목록이 뜹니다. 문구는 오른쪽 ‘방송 보드 문구’에서 바꿉니다. 칸을 빼려면 &hide=memo 처럼(notice, memo, turn, queue).

방송 화면 (가격표 · 현재 순서)1080 × 1920 (세로)
미리보기

오른쪽 위에 판매 상품 가격표와 현재 순서 닉네임이 뜹니다. 주소 끝에 &parts=turn 처럼 넣으면 원하는 것만(현재 시각은 &parts=tag,turn,clock), &align=left 는 왼쪽 정렬, &scale=1.2 는 크기 조절.

포케야호 프레임 (테두리 · 로고)1080 × 1920 (세로)
미리보기

방송 내내 떠 있는 포케야호 테두리와 로고·LIVE 배지입니다. 카메라 바로 위, 다른 화면들 아래에 둡니다. &text=오늘의 특가 처럼 배지 문구를 바꾸고(비우면 LIVE만), &logo=0 은 로고 빼기, &border=0 은 테두리 빼기.

힛카드 목록1080 × 1920 (세로)
미리보기

‘힛카드 축하’로 띄운 카드가 화면 왼쪽 위에 이번 방송분만 쌓입니다(최근 것이 위). 잘못 적은 건 판매 순서 카드 아래 힛카드 목록에서 지우면 됩니다. &count=15 는 보여 줄 줄 수, &align=right 는 오른쪽, &scale=1.2 는 크기 조절.

채팅 추첨 · 목표 게이지1080 × 1920 (세로)
미리보기

추첨을 열면 화면 가운데에 상품·키워드·남은 시간·참여 인원이 뜨고, 추첨하면 룰렛이 돌아 당첨자를 보여 줍니다. 참여자는 유튜브 채팅에 키워드를 쓴 사람이라, 이 화면이 OBS에 켜져 있어야 채팅을 모읍니다. 목표 게이지는 위쪽에 막대로 뜹니다.

OBS에 넣는 방법
  1. OBS 소스 목록에서 ＋ → 브라우저를 추가합니다.
  2. URL에 위 주소를 붙여 넣고 너비·높이를 표시된 크기로 맞춥니다.
  3. OBS를 통해 오디오 제어를 켜면 알림음이 방송에 함께 나갑니다.
  4. 사용자 지정 CSS 칸은 비워 두세요(배경은 이미 투명합니다).
  5. 아래 ‘테스트 알림 보내기’로 화면에 뜨는지 확인합니다.
